## Features

- Handles arithmetic operations.
- Handles chaining operations (e.g., `1 + 2`, pressing + again will result in
  `3 +`).
- Allows for clearing or deleting individual operands and operators.
- Full expressions are shown on display.
- Scrollable display when expressions get lengthy.
- Values are formatted with commas in thousands.
- Handles keyboard support on all devices.

## Installation

1. Clone the repository: 
  ```bash 
  git clone https://github.com/Calsjunior/retro-calc.git
  ```
2. Open `index.html` in any modern web browser.
